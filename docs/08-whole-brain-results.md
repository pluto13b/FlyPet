# 全脑本机实测结果

> 独立脑引擎的历史基准报告。数值对应当时指定工况，不能代表加入视觉观察和渲染后的整套应用占用；当前状态见 [项目进度](04-progress.md)。

日期：2026-09-19。**结论：这台电脑可以在 CPU 上实时运行本次完整连接图的简化 LIF 模型；2 ms 步长有余量，适合下一步接入。无需先安装 GPU 模拟栈。**

这份结论针对当时的独立神经引擎。后续已接入桌宠，最新状态见 [全脑接入](09-whole-brain-integration.md)，不要将本文独立基准数值当作完整产品占用。

## 实际加载的数据

正式使用 Shiu 论文仓库固定提交的配套 FAFB v783 数据，而非最初较小的 Codex CSV 导出。

| 项目 | 实际值 |
|---|---:|
| 模拟神经元 | 138639 |
| 保留连接对 | 15091983 |
| 突触接触总数 | 54492922 |
| 本地删除的连接记录 | 0 |
| 分类无法匹配的端点 | 0 |
| 编译数组总大小 | 约 175 MiB |

“连接对”是神经元之间的边，“突触接触”是该边聚合的接触数量，不能混算。所有神经元每个时间步均更新，脉冲通过真实边传播。

Codex 分类表有 139255 个神经元，比论文配套文件多 616 个；这 616 个不在配套连接发布中，未虚构为孤立节点加入。原始 Codex CSV 只有约 3415 万个接触，故改用论文文件的全部 5449 万个接触。两份数据的范围差异已记录，不能把“下载了分类表全部 ID”当成“已经加载所有连接”。

数据与来源：[metadata.json](../data/whole-brain/metadata.json)、[数据说明](../data/whole-brain/README.md)。

## 环境与方法

- 本机 i7-14650HX，16 核/24 线程，约 32 GB 内存。RTX 4060 Laptop 本次未使用。
- 本项目自研 Python LIF 引擎，Numba 编译单线程循环，NumPy 稀疏 CSR 数组；未运行外部桌宠核心。
- 每种工况先模拟 1 秒，再测 5 秒；加载与 JIT 预热分开。正式基准读取编译数组约 0.12 秒，已有 JIT 缓存的预热约 0.41 秒。第一次编译在引擎测试阶段完成，测试整体耗时约 4.75 秒，不能据此把首次编译也称为 0.41 秒。
- 三种输入：静默；10616 个光感受器的 50 Hz 外部刺激；32377 个中央脑细胞的 100 Hz 分散刺激。后两者是受控计算负载，不是视频理解任务。
- 模型使用膜电位、突触衰减、延迟、不应期、适应项；继承数据中的连接符号，抑制权重乘 1.5。这些是明确建模选择，未宣称复现原论文的生物学结论。

## 运行速度

实时倍率 = 模拟秒数 / 实际耗时。大于 1 表示算得比真实时间快。

| 步长 | 静默倍率 | 感觉刺激倍率 | 分散活跃倍率 | 活跃工况判断 |
|---|---:|---:|---:|---|
| 2 ms | 5.48× | 2.34× | 2.20× | 有实时余量 |
| 1 ms | 2.82× | 1.29× | 1.10× | 平均可实时，但余量偏小 |
| 0.5 ms | 1.42× | 0.92× | 0.80× | 活跃时未达到实时 |

2 ms 感觉输入工况有 81820 个神经元放电；2 ms 分散活跃工况有 65516 个神经元放电，5 秒产生约 257 万次脉冲。因此“能实时”不是用零活动得到的结论。不同步长的活动率也不同；更改步长后需要重新校准行为读出，不能只视作纯粹的速度开关。

## 持续实时调度与资源

两次均以分散活跃输入运行，每 50 ms 推进 50 ms 模拟时间，持续 30 秒。没有丢弃模拟步。

| 指标 | 2 ms | 1 ms |
|---|---:|---:|
| 墙钟时间 | 30.00 s | 30.00 s |
| 进程 CPU 时间 | 17.16 s | 25.59 s |
| 占一个逻辑核的 CPU 时间比例 | 57.2% | 85.3% |
| 按 24 逻辑处理器归一的整机比例 | 2.38% | 3.55% |
| 采样峰值 RSS | 349.4 MiB | 348.3 MiB |
| 600 个调度块中超时次数 | 0 | 144 |
| 最大落后时间 | 0 ms | 24.7 ms |

2 ms 持续测试共发放约 1540 万次脉冲，74563 个神经元有活动，全脑平均约 3.70 Hz。1 ms 虽然平均跟得上，但局部计算峰值超过块预算，所以默认更适合选 2 ms。

这些百分比是 CPU 时间口径，不是功耗测量，也不能解读成只用了 2.4% 的一个核心。RSS 包含解释器/JIT/数据，但不包含桌宠 Electron、屏幕截图、3D 绘制和观察面板。两次测试分开进行，CPU 频率和系统背景负载会变化；结果不保证繁忙或省电状态下仍有同样余量。

## 对产品的决策

1. **可以继续全脑路线，内存不是当前主要障碍。** 不需要因预想的资源压力继续限制在 668 个神经元。
2. 首次集成以 **2 ms、独立脑进程** 为起点，避免神经计算阻塞 Electron 窗口与动画；保留现有身体/界面。
3. GPU 本轮未测：CPU 已满足首个实时目标，暂不增加 GPU 依赖和下载成本。
4. 接下来要验证真实屏幕视觉到全脑的输入、下行输出的稳定读出，以及全脑状态保存。性能通过不代表已经获得食物识别、学习或完整生物行为。
5. 本次“全脑”是该公开成年雌蝇脑数据版本的完整网络，不含完整腹神经索/身体。没有把简化动力学描述成完整生命复制。
