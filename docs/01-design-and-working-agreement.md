# FlyPet 工作约定与产品方向

更新：2026-09-19。当前实现以 [README](../README.md) 和 [项目进度](04-progress.md) 为准；本文件维护已确认约定，不把愿景等同于已交付功能。

## 工作方式

- 工作区是 `D:\Desktop\FlyPet`，优先使用本机已有环境。
- 下载、依赖、缓存、临时文件和运行数据均限定在工作区。下载可使用 Clash `http://127.0.0.1:7897`，不修改系统代理。
- 先写必要文档，再执行；完成后同步当前状态、使用方式、验证与限制。
- 优先复用 GitHub 超过 100 stars 的相关项目；低 star 高相关候选可参考，但需明确理由。
- 产品和集成核心自行维护；科学模型优先复用作者实现、预训练参数与验证范围，不由非生物专业团队凭直觉拼出生理机制。
- 目标是好玩的桌面数字动物，不做成论文项目。先用预训练模型，只有具体体验问题需要时才考虑小规模微调，不从零训练、不建大数据集、不做大规模消融。
- 不因预想的硬件压力先裁剪目标；用实际性能结果决定工程安排。8 GB 显存/32 GB 内存不是已经验证全部训练配置的保证。
- 文档维护与实验结果分开：只核对已有报告时，不写成重新运行过测试。
- 允许针对具体体验问题做轻度训练／微调，但不运行整天训练。默认单次离线实验上限 10 分钟、同轮累计 30 分钟，触顶保存并停止，不自动隔夜续跑。优先已有 Conda GPU 环境，详见 [实现与预算](25-life-layer-implementation.md)。

## 产品方向

- 像一只在电脑里自由生活的小果蝇，可以笨拙，不需要贴心讨好用户。
- 屏幕世界尽量简单，允许遮挡文字、被鼠标惊吓；声音是允许的方向，当前尚未实现。
- 用户能以上帝视角查看感觉、真实模拟活动、内部状态和行为来源。
- 字幕简短，例如“饿…”“吃。”“跑！”，来自内部状态，不接大模型编写人格。
- 保持同一个体及经历；允许合理简化，强调感知与行为的可解释联系。
- 长期希望能在美食视频附近探索、进食，但现有模型能力必须实测，不从连接图完整性推断食物识别或学习。

## 当前已接受的实现边界

- 完整配套脑图运行与身体控制已接入；官方 flyvis 保持原模型，空间响应可观察，冻结价值可经工程接口辅助转向；未重建到全脑的视觉神经级连接，未接入在线学习。
- 手动糖水作为可用的宠物机制，支持饥饿消退与状态保存，不声称是神经味觉回路或视觉食物识别。
- Life Layer A/B 已实现桌面放置、接触停下摄入，以及迟滞／保持／近期威胁门控；按 [26](26-life-layer-first-implementation.md) 使用。主动视觉趋近和在线学习 C/D 尚未接入。
- 真实光标合成进图像；几何鼠标感知是独立输入，界面明确标注。
- 静态解剖背景与动态活动探针分别标明，不随机闪烁伪造全脑活动。
- 关闭期间时间暂停；现有正式存档与验证个体分开。
