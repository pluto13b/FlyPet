# 观察室截图与控件说明

后续修正：默认整窗灰色遮罩会误伤视觉，现已改为可选且默认关闭。以 [30](30-visual-input-visibility.md) 为准；本文件保留当时修复系统截图的记录。

2026-09-20。根因：观察室复用了 `makeWindow` 默认的 `setContentProtection(true)`，因此 Windows 截图工具无法正常捕获；不是用户操作错误。

改为允许观察室系统截图。为避免视觉反馈循环，在两条感觉采样链路中将可见观察室区域填成中性灰；屏幕原图和系统截图不受这层内部处理影响。苍蝇本体继续使用原有内容保护，糖水保持可采集。

同时明确“暂停模拟”“视觉采样”“视觉辅助转向”“鼠标感知”的不同职责；不改变开关功能或用户已有设置。

内部遮罩由 `screen_mask.py` 完成，按显示器物理坐标裁剪；实际糖水圆片像素在遮罩后保留，鼠标仍正常合成。糖水位置仅用于避免自身 UI 遮罩误删它的实际像素，不进入价值评分或目标转向计算。

当前按可见且未最小化的控制台窗口矩形遮罩，不分析它是否被其他窗口部分遮挡；控制台隐藏后取消该区域遮罩。用户使用系统截图不会得到这层灰色遮罩，它只存在于苍蝇的感觉输入中。

遮罩单测覆盖负坐标、区域外不变、糖水像素保留。桌面测试通过改变控制台内两种背景颜色、从 Windows 屏幕采集读取相应变化，检查原生截图是否能看到控制台；颜色比较允许 Windows 色彩管理的数值差异。本轮没有操作 Windows 截图工具的选区或自动保存界面。

最终验证：`desktop-smoke.json` 时间 2026-09-20 06:42:31 UTC，`passed: true`，`consoleNativeScreenshot: true`，采集到的两种颜色分别为 `[225,37,217]`、`[37,225,217]`。同时通过原有空间视觉、双屏糖水、进食、暂停及保存检查。测试临时颜色已恢复，正式窗口未做颜色干预。
