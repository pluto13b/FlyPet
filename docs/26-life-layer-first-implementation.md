# Life Layer A/B 首轮实施记录

2026-09-20。依据已批准计划实施稳定行为和桌面接触糖水；本轮不训练、不接入视觉目标评分。先修改代码和独立测试，完成后填写实测结果。

固定约定：探索偏置保持 2–5 秒并保存随机状态；鼠标威胁窗口 300 ms、强度 0.25；普通动作保持 walk 1.2 s、groom 1.5 s、rest 0.8 s，行走阈值 2/1 Hz、梳理 8/5 Hz。威胁和糖水接触可打断。单滴糖水半径 20 DIP、6 秒储量，落地接触且速度低于 2 DIP/s 才摄入，每秒降低饥饿 0.12。

旧版直接进食计时清空，原个体和脑动态保留。新糖水、动作保持和随机状态进入现有配对存档。所有验证使用独立 smoke 个体。

## 已实现

- 去除时间正弦转向／探索，改为固定种子可续接的低强度探索偏置，2–5 秒更新一次。
- 行走 2/1 Hz、梳理 8/5 Hz 迟滞与 1.2/1.5/0.8 秒动作保持。疲劳、接触和有效逃逸可打断。
- 普通逃逸需 GF 与最近 300 ms 内强度 ≥0.25 的几何鼠标威胁共同支持。手动 GF 干预独立标注，仍可触发。
- “放置糖水”进入各显示器的临时选择层，左键选位置，Esc 取消；“移除糖水”和再次放置均生效。正常显示层鼠标穿透。
- 糖水是可被截图采集的独立窗口，苍蝇与观察室继续受内容保护；没有把糖水坐标注入神经感觉输入。
- 落地接触后减速，速度低于 2 DIP/s 才摄入；飞越、离开、暂停不会消耗。吃饱或储量耗尽后停止。为避免刚吃饱后被微小饥饿增量反复触发，新进食要求饥饿超过 5%；已开始的进食可持续到饱。
- `feedings` 从此记录实际开始摄入次数；旧历史计数保留，不重新解释其历史意义。最近一次摄入记录时间、位置和摄入时长，尚未发送学习奖励。
- 沿用配对检查点保存糖水、保持时间和随机状态，旧直接投喂计时清空。无独立新存档体系。
