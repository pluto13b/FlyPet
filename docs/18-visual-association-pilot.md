# 页面封面的视觉关联试验

2026-09-19：独立实验，不改正式个体。用用户给定的 B 站截图截取第一、二排封面。训练对象选为首排第 4 和第 6 张，默认第 6 张与糖水配对；封面序号仅用于实验调度和展示，不作为模型输入。

输入链路：封面真实像素 → 作者 BoxEye 灰度采样 → 固定预训练 flyvis 的空间 Tm3 活动 → 固定随机投影 → IncentiveCircuit KC 输入与局部学习。随机投影是明确的工程编码，并非已标定的生物视觉到蘑菇体通路；不训练图像分类器，不注入食物标签或目标坐标。

实验先测无奖励前后读出，再做冻结学习、改为奖励另一张封面的对照。交换封面左右位置时仍从相应图像取输入，验证偏好跟随内容。轻微亮度变化作为同图变化测试；其余封面仅作未训练图片探测，不据此声称食物类别泛化。页面选择界面展示实际模型评分，不伪造自主爬行。

作者模型使用现有项目环境。学习计算规模很小，先在 CPU 跑；已有 GPU 原型用于此前的批量气味实验，不为本次视觉接入迁移全模型。全部文件和缓存保存工作区。

## 结果（原图裁剪修正后）

原截图是 2560×1229，聊天预览是约 2048×983。首次检查发现直接使用预览坐标导致裁剪偏移，已按原图尺寸换算、重算视觉特征并重跑；下列结果和最终 JSON 均来自修正后的完整封面，首次结果不作结论。浏览器已实际核对人物讲课和餐盘封面。

| 独立训练条件 | 人物封面 A 平均读出 | 餐盘封面 B 平均读出 | 16 个种子 |
|---|---:|---:|---|
| B 与糖水配对 5 次 | 0.0073 | 0.3091 | 16/16 更偏向 B |
| 从初始状态改为 A 配对糖水 | 0.2736 | 0.0144 | 16/16 更偏向 A |
| 相同训练过程，冻结可塑性 | 0 | 0 | 未形成偏好 |

这些是三组独立模型，第二行不是在第一行记忆上反转训练。数值是 MBON 三对趋近减回避输出的平均，单位任意，不是食物概率。测试使用新的短时状态、冻结学习权重，只读出训练后的图像价值。

B 训练组在两张图同时降低亮度 15% 后仍有 16/16 更偏向 B；仅支持这两张已见图片的一种光照变体，不能当作对任意美食泛化。其余 10 张封面为未训练探测，没有食物分类标签或类别准确率。

用同一张裁剪图置于左／右槽位，评分保持不变：位置不进入编码。这是槽位独立性检查，不是自主扫描、目标定位或视角改变的导航试验。页面不播放预设苍蝇爬行，也尚未驱动正式身体。

## 接口与保存

每张封面等比缩放并在 403×403 中性灰底上居中，输入官方 BoxEye；官方 flyvis 从相同灰背景稳态运行 5×20 ms。保留 721 个 Tm3 单元的空间活动，按图像去均值和 L2 归一化；每个种子生成一份固定的 721→200 随机投影，作者模型保留其中 20 个活跃 KC。投影不根据图片标签或奖励训练；可塑性只在作者学习回路内发生。

这里改变了学习模型的输入维度／KC 数量，是工程视觉编码适配。不能称为真实视觉到蘑菇体的解剖复现。官方视觉权重与作者学习公式没有改动。封面的标题叠字、人物与背景也都属于像素输入，未证明模型只看食物本体。

运行核心（含已安装官方模型加载、特征编码及 48 个条件/种子组合）约 8.13 秒，CPU；解释器导入和页面展示不计入。无需为本次小实验追加 GPU 安装。
