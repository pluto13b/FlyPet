# 常驻性能优化

2026-09-21。用户反馈运行占用偏高；先测量、后实施，不通过缩小全脑或关闭视觉冒充优化。

## 本轮方案

1. 用进程树统计 CPU 时间增量、工作集/私有内存，包含 Windows venv 启动器下真正的 Python 子进程；记录可复用的前后测量口径。GPU 整卡读数不能直接归因 FlyPet。
2. 对固定权重 flyvis 推理检查重复参数展开、逐边临时张量与中间状态保留。可将固定线性连接改为预编译稀疏算子，但必须保持同一连接、权重、激活与 20 ms Euler 步，并与官方实现逐步对比。未通过精度验证则不启用。
3. 减少重复截图、重复 JPEG/空间响应传输与重绘；隐藏/最小化观察室暂停其可视化工作，保留身体与感觉运行。身体动画按实际需要刷新，保留精细模型和运动连续性。
4. 全脑进程只做测量支持的分配/采集优化；保留 138639 神经元、15091983 连接、2 ms 步长、原个体和配对检查点。
5. 运行核心测试、视觉等价验证和桌面集成检查，保存性能前后对比。维持本轮自然观察的版本边界：若重启发生在观察结束前，保存部分报告并注明维护中断，优化后另开一轮，不拼成混合版本的 30 分钟结论。

所有新增脚本、基准结果、模型编译/运行缓存限于本项目目录。无需训练，不新增模型下载。

## 结果

已完成。最终对照见 [comparison.json](../output/performance/comparison.json)，原始数据为 [参考执行路径](../output/performance/app-reference.json) 与 [优化执行路径](../output/performance/app-optimized.json)。本机 24 个逻辑处理器、独立测试个体、相同桌面 smoke 流程，分别采样约 20 秒：

| 指标 | 官方参考执行路径 | 优化执行路径 |
|---|---:|---:|
| 进程树占整机 CPU 容量 | 19.92% | 5.42% |
| 累计使用 CPU 核心数 | 4.78 | 1.30 |
| 进程工作集合计 | 1998.5 MiB | 1743.9 MiB |
| 私有内存合计 | 2327.0 MiB | 1971.4 MiB |
| 视觉进程工作集（实际 Python） | 845.6 MiB | 575.4 MiB |
| 视觉更新速率 | 约 10.8 帧/秒 | 约 14.6 帧/秒 |
| 同区间脑模拟推进 | 20.4 秒 | 20.4 秒 |

CPU 减少约 **72.8%**，工作集合计减少约 **12.7%**，视觉进程 CPU 从约 3.68 核降至约 0.43 核。两组对照都使用新的窗口管理/绘图优化，因此这张表主要反映视觉执行路径的收益，没有把隐藏绘图优化额外算进降低比例。工作集是各进程之和，可能重复包含共享页；不等同于系统唯一物理内存用量。测试采集器也在子进程树中，约占 120 MiB，两边保持同一口径。

以上是有界场景实测，不是所有屏幕内容或整机负载下的保证。未把整卡 GPU 使用率归因 FlyPet，也未承诺全部 GPU 显存占用下降。

25 项 Node 测试通过；空间视觉测试、同输入数值验证与桌面 smoke 通过。最终桌面报告见 [optimized-desktop-smoke.json](../output/performance/optimized-desktop-smoke.json)，包含糖水像素、鼠标输入、脑图交互、全脑干预、存档恢复，以及隐藏观察室停绘而感觉继续。最终同输入链路最大差异：复眼亮度约 `1.37e-6`、空间活动约 `4.07e-6`、冻结价值约 `1.48e-9`；见 [observer-parity.json](../output/performance/observer-parity.json)。

## 已实施的计算与渲染调整

- `src/vision/frozen_dynamics.py` 从官方模型展开固定权重一次，改用 SciPy CSR 乘法实现相同的 `PPNeuronIGRSynapses + ReLU` 方程。保留 45669 单元、1513231 条原连接与 20 ms Euler 步，不训练、不剪枝、不降为小模型。仅适用于已固定权重的这个模型，其他动力学会明确拒绝使用。
- BoxEye 保持作者的受体坐标、13×13 求和平均、零填充及小图缩放，只计算最终会被采样的 721 个位置。不会扩大/缩小视野或减少采样点。
- 预热也使用同一 CSR 方程，只保留最终状态；三路相同灰背景共享预热结果的副本。释放训练参数读出对象，避免启动时保留百万级逐边中间张量。一次中间版本曾增加内存，已由分阶段内存诊断定位并修正，未作为交付结果。
- 周边全屏截图存在时，前方图从同帧裁切；没有遮罩时复用取景变换；隐藏/最小化观察室不生成 JPEG 与空间活动列表。感觉推理和行为继续。
- 观察室隐藏后停绘脑图/肖像，神经时间不变时不重复更新脑点云，画面不变时不重复绘制复眼；身体运动上限 60 FPS、梳理/进食 30 FPS、停留 15 FPS，暂停后不持续绘制相同身体。
- 苍蝇像素位置不变时不调用原生窗口移动；糖水位置/文字未变时不反复移动、隐藏和发送 IPC。糖水首次显示或重放置时抬至正确前景层，避免被透明苍蝇/观察窗口遮挡。
- 全脑 LIF 保持原始 2 ms 步长与全量连接，只释放构建后不再使用的原始权重副本；神经状态、随机状态和个体 ID 均保留。

## 可复现验证

```powershell
. .\scripts\vision-env.ps1
npm.cmd test
.\.venv-vision\Scripts\python.exe src/vision/benchmark_dynamics.py
.\.venv-vision\Scripts\python.exe src/vision/benchmark_observer.py
.\.venv-vision\Scripts\python.exe src/vision/test_spatial.py
$env:FLYPET_PERF='1'
$env:FLYPET_REFERENCE_VISION='1'
npm.cmd run smoke
$env:FLYPET_REFERENCE_VISION=$null
npm.cmd run smoke
$env:FLYPET_PERF=$null
```

测试使用 `.runtime/smoke` 独立个体。环境变量 `FLYPET_REFERENCE_VISION=1` 只用于对照原始官方执行路径；正常启动默认优化版。`measure-performance.ps1` 跟踪整个应用子进程树，包含基础 Python 可执行文件，避免误把 venv 启动器的零 CPU 当作模型占用。原始进程树统计也包含临时性能采集进程，因此不同口径不可混加比较。

数值对比包括单路和三路共各 180 步随机输入、128/403 像素 BoxEye、整条含冻结价值评分的视觉观察链路。最后一项使用合成桌面与固定光标条件，不采集用户其他应用；允许浮点求和顺序导致的微小差异，不声称逐比特相同。桌面验收另验证隐藏窗口停止绘图但视觉帧继续增加。

初次进程采样时正式个体已被用户暂停，相关 `before-full-tree.json` 只用于诊断暂停状态，不能作为运行版优化收益的基线。有效对照是后续独立个体、相同桌面流程中的 `app-reference.json` 与 `app-optimized.json`。
