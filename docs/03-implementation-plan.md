## 目标与代码归属

FlyPet 自己维护感觉输入、神经模拟、行为读出、内部状态、持久化、字幕与观察界面。开源项目用于数据、身体几何和必要基础库，不直接复制一个桌宠换名，也不同时接入数套脑引擎。

首轮用 DesktopFly 已提取的 FlyWire 668 神经元真实连接数据作为小规模可运行基线；这是验证用回路，**不是最终脑模型选型，更不是全脑**。我们编写自己的 LIF 引擎和状态/行为循环。仅复用其程序化身体几何，保留 MIT 署名；不复用其行为决策器。科学来源与人为建模参数在界面和文档中区分。

## 分阶段推进

### A：本轮交付——可运行的自研核心基线

- 工作区内依赖、缓存、临时目录和用户状态；提供 Windows 启动脚本。
- 下载固定版本的小型连接图，记录来源和许可，不下载完整 GB 级数据。
- 自研 1 ms LIF 模拟，真实连接图、群体读出、活动探针；人为增益和感觉编码明确标注。
- Windows 透明桌面身体，自由活动；动作/字幕/观察面板读取同一状态。
- 鼠标几何感觉通过 LC4/LPLC2 注入，只有 GF 神经输出触发逃逸，不设置“鼠标近就直接逃”的行为捷径。
- 真实屏幕低分辨率采样和左右复眼预览；先做亮度/变化输入的工程化感觉编码，不冒称已实现真实完整视觉回路。
- 观察面板可以暂停、刺激群体、查看实际模拟神经元与活动、查看状态与感觉来源。
- 保存个体 ID、运行年龄、位置、内部状态和神经状态。离线阶段先暂停时间，明确为阶段性规则，不新增衰老/死亡惩罚。
- 糖水、奖励学习和美食视频自主进食留待 B/C；A 不用假的识别逻辑填补这些能力。

### B：视觉模型实验与选型

在 A 的可观察基础上比较当前感觉桥接、fruit-fly 视网膜及必要时 flyvis。使用静止、平移、扩张和真实视频片段，检查视觉→神经→动作的实际因果及本机开销。根据结果决定扩大网络或更换视觉模型。鼠标感觉与纯像素实验分开标注。

### C：进食、经验与连续个体

先写感觉/奖励规则，再做糖水与最小学习实验；保存权重变化并验证重启后保留。随后决定网页自由觅食的实现；不把嗅觉学习直接解释为视觉食物识别。完善疲劳、离线时间、声音与长期经历。

## 本轮结构

- `src/core`：自研神经引擎、感觉编码、统一状态、行为与快照。
- `src/main`：Electron 窗口、屏幕采样、磁盘保存和运行循环。
- `src/renderer`：透明身体与观察面板。
- `vendor/desktop-fly`：仅身体几何及必要几何辅助、许可。
- `data`：固定版本的小型连接图和数据许可。
- `scripts`：工作区环境设置、安装、启动与验证。
- `tests`：少量有信息价值的因果、持久化和感觉测试。
- `.cache`、`.runtime`、`output`：工作区内缓存、个体状态与验证结果。

## 验收与停止点

1. 安静输入与感觉刺激产生不同神经响应；GF 沉默时感觉刺激不能触发逃逸；直接刺激 GF 能触发逃逸。
2. 动作与字幕来自同一状态，暂停后状态不继续漂移。
3. 保存/恢复保持同一个体与神经状态；实际重启检查 ID 连续性。
4. Electron 启动、透明身体渲染、观察面板与实时屏幕输入可检查；保存截图及运行结果。UI 未实测部分必须明确写出。
5. 启动和依赖流程的缓存/临时文件路径都指向工作区。

达到 A 的运行与验证边界后更新进展文档，交付可运行入口与真实限制；不把 B/C 标记成已完成。
