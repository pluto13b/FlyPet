# 密集三维脑图

> 三维脑图已完成。以下包含选型计划与验收结果；当前功能总览见 [项目进度](04-progress.md)。

目标：接近用户参考图的浅色密集三维脑轮廓，优先复用现成代码，不改神经模型。

选型：复用 DenisSergeevitch/desktop-fly（此前核实超过 1000 stars）的 three.js 点云构建代码；使用当前 three.js 自带 OrbitControls 交互。另查到 snedea/flybrain（本轮 API 133 stars），但现有底座已经提供兼容的点云实现，无需引入另一整套应用。

DesktopFly 固定提交 32b00011e83c3dc85fa3ea0b3934155b04f1635d 的 etl.py 对原始坐标抽样，输出 23210 个点。本轮下载同源 FlyWire v783 coordinates.csv.gz，使用全部可用代表坐标，保留原始 root ID 与同一坐标归一化方式。坐标代表解剖位置，不冒称是神经纤维完整形态或逐突触重建。

显示分两层：浅色静态解剖点云；现有 668 个真实 ID 对应的动态探针。面板明确标注两者数量。支持拖动旋转、滚轮缩放、复位、自动旋转和隐藏活动层。活动来自已有全脑实际输出，不增加第二个模拟器，不随机点亮背景。

验收：核对坐标/探针对齐、默认与放大后的三维效果、旋转缩放控制、持续运行及已有存档。下载和缓存仍仅在工作区，Clash 7897 下载。
