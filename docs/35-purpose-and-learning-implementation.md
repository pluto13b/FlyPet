# 持续目的与个体摄入学习：实施记录

2026-09-21。用户确认推进，允许必要训练。先记录范围，再实施。

## 本轮交付

1. 修复停留/梳理时背景身体转向；明确的查看/接近可以转向，微动作不移动实际视野。
2. 复用官方 flyvis，增加基于实际取景像素的少量局部对比区域候选。区域经官方 Tm3 特征和现有价值回路评分；像素中心/范围由取景几何转为桌面 DIP，不读取糖水坐标。它是工程区域提取，不宣称物体识别。
3. 维护“检查区域”与“寻找新线索”两个持续目的，允许短时重新确认；按到达、消失、无进展、威胁/疲劳结束。短时访问记录只减少重复探索，不当作奖励记忆。休息先就地进行。
4. 实际摄入与最近确认且在接触附近的视觉线索配对，调用现有 IncentiveCircuit 作者的局部多巴胺可塑性规则，更新个体 KC→MBON 权重。普通观察不训练；同次进食不按渲染帧重复发奖。无可靠配对只降低饥饿。
5. 目标、访问状态与个体学习权重进入已有配对检查点；旧存档默认无目标、从现有离线记忆起步。显示当前目的、进展/放弃理由、实际学习事件，并接入行为观测端口。

神经输出继续影响速度与局部转向，GF 逃逸优先。目标维持和目标方向属于明确工程协调；不宣称整个链路是全脑自发涌现。正式个体不做自动实验、不注入实验奖励。

## 实验与停止条件

先用独立个体/副本进行少量真实视野的简单线索配对，验证看见、接近、撤走/移动、摄入、选择变化和重启保留。训练单次不超过 10 分钟、同轮累计不超过 30 分钟；本轮优先使用已有 CPU 小回路进行事件更新，只有实测需要时才动用 GPU。不会训练整个全脑或重做视觉。

验证静止不转、目标跨动作保持、视觉关闭/失效停止盲目趋近、威胁可打断、不同显示缩放、真正接触才奖励、重复/过期奖励不更新、配对存档恢复。首版目标是简单近场线索和可见糖水的闭环，不声称解决了任意 B 站美食泛化。

## 结果

已实现并通过以下有界验证：

- **30 项 Node 测试通过**：静止/梳理/进食不被背景或墙边转向推着转；区域目标可持续接近；重新确认、撤走/移动、关闭视觉、威胁打断；探索换区域；DNp09 输出为零时目标不能自行驱动平移；目标与访问记录可恢复。
- **实际视觉模型的独立学习小试验**：CPU，8 次作者 DPR 协议配对，首次运行含初始化约 5.98 秒，追加校验的一次约 4.23 秒。初始线索 A/B 读出为 `0.0298/0.0338`，配对 A 后为 `0.2678/0.1918`；换位置后为 `0.2646/0.1890`。提高了配对线索的相对偏好，但另一线索也有泛化提升，不当作类别识别准确率。验证重复/过期奖励拒绝、个体 ID、恢复，以及 100/125/150% 缩放和负坐标下的 DIP 一致性。[结果](../output/purpose-learning/learning-pilot.json)
- **全脑闭环**：独立 138639 神经元个体接收测试屏幕像素，经生产视觉/目标/运动代码约 7 秒模拟时间后，从 105 DIP 外自行接触并摄入。触发真实摄入关联，读出约 `0.0296 → 0.1590`；重新启动脑与视觉进程，验证配对检查点中的个体 ID、脑时间与学习权重恢复。墙钟约 25.7 秒包含进程初始化和重启。[结果](../output/purpose-learning/closed-loop.json)
- **Windows 桌面验收**：独立测试个体，真实可截图糖水窗口与空白桌面测试背景，初始距离 110 DIP；约 10.32 秒后自主接触、摄入并更新个体记忆，读出约 `0.0271 → 0.1616`。同时通过已有鼠标像素、不同显示缩放下糖水放置、Esc、窗口隐藏、神经干预、存档和观测端口检查。持续 30.13 秒推进 30.10 秒脑模拟，最大队列 113 ms。[桌面结果](../output/verification/purpose-desktop.json)、[完整验收](../output/verification/desktop-smoke.json)

上述实验奖励仅作用于测试副本；`output/purpose-learning/paired-memory.npz` 没有覆盖正式个体。正式个体从现有离线初始记忆继续，今后实际摄入才更新自己的权重。没有新模型下载，没有训练全脑/官方视觉，没有启动 GPU 长训练；训练试验与开发耗时分开。

## 实现口径与使用

- 在苍蝇附近、较清楚的背景上放置糖水，观察“检查视觉区域 → 定向/接近 → 接触摄入”。光标靠太近仍可能吓跑它。进入视野、选中目标和学到偏好是不同事件，不保证每次放置都立刻过去。
- 目标来自最多 3 个灰度局部对比区域；区域裁剪经官方 Tm3 与同一个体价值回路评分。区域位置来自截图投影，不从糖水对象获取。当前区域提取并不等于物体检测或食物理解，拥挤界面可能检查文字、图标和其他高对比区域。
- 检查目的按距离估计分配 8–30 秒上限，连续 5 秒无位置进展则放弃。约 0.85 秒没有新确认先停下重看，1.8 秒未再见结束。已检查区域短暂抑制重复选择，访问记录随 90 秒模拟时间衰减；这些都是可见标注的工程初值。
- 运动强度使用 DNp09 读出的 0.45 秒平滑与有界映射，目的通过小幅工程输入调节行走驱动。初次全脑试验曾因直接 Hz→速度映射过低而未走到目标；据实测修正了读出映射，没有绕过神经输出给固定移动速度。
- 每次开始摄入只配对一次；目标需近期被看到且在接触附近，worker 还检查图像缓存时效。无可靠线索只更新饥饿。学习采用作者 `IncentiveCircuit` 的 DPR，不在观察每一帧时更新、不把未找到当作惩罚。
- `visualLearning` 与身体、全脑一起写入现有配对检查点；公共离线记忆不修改。视觉进程初始化恢复相同个体的记忆；控制台显示持续目的、当前进展、最近放弃原因及摄入配对次数。

本轮实现时证明了简单近场线索的定位、接近和摄入学习链路；其后的 30 分钟自然观察见下节。仍未证明复杂 B 站页面的美食泛化，不用旧版仅约 5 分钟有效活动的数据宣称已解决整体“宠物感”。

正式版本已验证启动、窗口可见及配对保存：个体仍为 `8a7299a1-542b-4e3c-b1e8-49546be21dcf`，`visualLearning.petId` 与之匹配，学习更新次数为 0（没有注入测试副本的奖励），保留用户原先的暂停状态。随后应用已退出，最后存档为 `2026-09-21T13:31:53.021Z`，启动/保存过程没有新增应用错误；重新打开后点击“继续模拟”可体验新版。
