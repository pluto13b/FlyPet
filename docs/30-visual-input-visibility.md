# 视野灰块修正与输入对照

2026-09-20。用户截图中前方复眼几乎均匀灰色、三个局部价值相同。当前代码会将整个可见观察室矩形填灰；苍蝇在观察室上方时，视野可能被此工程遮罩大面积覆盖。这不是实际果蝇空间分辨率的证明。

本轮修正：默认允许看见观察室像素；增加明确的“忽略观察室”开关，开启时才填灰，且保存用户设置。控制台仍可系统截图。允许看见自己界面会产生画面反馈，界面提示可将观察室移开或主动开启遮罩，不伪造被窗口遮住的底层桌面。

面板默认并排显示原始采集画面（人类对照）与官方模型复眼输入；运动神经图用切换查看，避免多个小图挤在一起。原始画面按同一身体朝向和取景范围投影，保留颜色用于对照，但不宣称灰度模型拥有色觉。显示输入是否近乎单色及遮罩状态。预览仅在内存传送，不写入个体存档。

不通过平滑放大冒充感受器增加；作者 BoxEye、721 列输入和模型权重不变。本轮解决人为遮挡和可解释展示，未宣称完整复现果蝇视觉。

## 已实现与验证

- 默认“忽略观察室：关”，新字段随个体保存；旧存档默认关闭，不再无提示地把可见控制台区域填灰。开启时保留明确提示，遮罩策略变化立即重建周边基线并刷新局部价值。
- 采集彩色参考图、复眼输入与鼠标标记按同一帧配对显示，约 5 Hz 更新；神经动态继续独立计算。彩色参考不是新加入的模型色觉。
- 默认看“采集画面＋模型复眼输入”，可切换“运动神经活动”；默认布局给视觉更多空间，长说明折叠。单色提示以输入第 5–95 百分位范围判断，避免一个小鼠标掩盖大面积灰面。
- 移动苍蝇保持原更新频率，较大的控制台诊断内容约 15 Hz 推送，控制台隐藏时不推送；避免原始预览加入后每个身体时刻重复传输图片。
- 原始预览及对应复眼数组不写入个体配对存档。验证截图仍可能包含采集画面，存于项目 `output/verification`。

[空间输入检查](../output/verification/spatial-vision.json) 已复现并验证“有细节的采集画面→遮罩后单色→关闭遮罩恢复细节”，并验证冻结读出不变。[20 项核心测试](../output/verification/core-tests.txt) 通过。[桌面报告](../output/verification/desktop-smoke.json) 2026-09-20 08:08:36 UTC 为 `passed: true`，验证预览载入、视图切换、忽略观察室开关和原有功能；31.33 秒墙钟推进 31.15 秒模拟，最大待算时间 141 ms。
