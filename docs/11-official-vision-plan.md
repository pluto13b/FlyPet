# 官方视觉模型最小接入

> 该阶段已完成：实际采用 CPU 运行未改动的官方模型，完成刺激验证与观察室接入。身体接口未接通。交付见 [12](12-official-vision-results.md)，当前状态见 [项目进度](04-progress.md)。

目标：原样使用官方 flyvis 预训练模型，获得经过作者验证的明暗/运动视觉能力；不训练、不微调、不自行设计新的生理机制。

## 本轮范围

1. 工作区内独立环境，复用本机 Python 和 RTX 4060；下载官方发布权重与所需代码。模型结构、动力学和参数不改。
2. 先完成官方模型加载和少量输入验证：亮/暗、左右移动、页面滚动式运动与一段可取得的实际桌面画面。保存实际响应和结果。
3. 接入桌宠的屏幕输入与观察界面，明确显示官方模型的响应。只有有依据的输出映射才用于动作，不为追求演示效果添加物体识别/颜色识别或虚构神经连接。
4. 若官方视觉图与现有全脑不能直接一一对应，保留清楚的模块边界，避免双算同一通路并冒称是同一标本的完整视觉。先交付已验证的可运行能力，记录仍需处理的接口。

## 验收与停止点

- 使用官方预训练权重成功推理，证明移动方向/明暗变化产生相应神经群体差异。
- 实际桌面输入可进入模型，观察面板展示真实输出并标出来源。
- 原有个体和全脑存档保持可恢复。
- 达到可用效果后停止扩展，不建数据集、不做大型训练/消融、不追加全套视觉生理重建。

所有下载、模型文件、环境及缓存位于本工作区；下载通过 Clash 7897。当前正式桌宠保持运行，集成验证通过后再更新。
