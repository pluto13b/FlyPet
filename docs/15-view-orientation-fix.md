# 官方视觉取景方向修正

用户反馈：鼠标放到身后反而显示在中心，放到眼前显示在边缘。

根因：原取景框以身体位置附近为中心但不旋转；临近显示器边缘会整体平移以保持矩形完全在屏内。官方 BoxEye 还只读取矩形中央的固定像素范围。它是局部俯视截图，不是朝向一致的眼睛，不能将现象归因于果蝇与人类视觉差异。

本轮只修改输入坐标适配：以身体 heading 定义前方与左右，局部视图上方为更远的前方、下方为近身；取景中心位于身体前方 80 DIP，视图宽度为 320 DIP。它是明确的工程取景约定，不是宣称测得的果蝇视野角度。

边缘策略：保持该中心与方向，屏外区域使用中性灰填充，不平移取景框。鼠标图像先合成进真实屏幕，再和图像一起旋转/缩放；位置标记使用同一个逆变换。DPI 转换在输入端完成。

验收：四种朝向的前后左右关系正确；靠边时中心不漂移；图像与鼠标标记对齐；官方模型参数和测试图案不改。更新相关使用说明，并用桌面检查验证运行与存档。
