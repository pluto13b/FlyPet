## 实测结论

**受控线索—奖励关联已成功，保存的 GPU 学习权重能改变无奖励环境中的行为；直接自由探索学习及完整反转尚未达标。** 不将部分成功写成桌面个体已经会学习。

用户提示后找到现有 Conda 环境 `D:\Desktop\deeplearn\conda_envs\tudui`，PyTorch `2.13.0+cu132`，CUDA 可用，显卡为 **RTX 4060 Laptop GPU / 8 GB**。没有安装新环境。为实际比较 GPU，额外写了一个小型 PyTorch 批处理计算适配，逐步核对作者 NumPy 实现；原始上游文件保持不变，均与固定提交的 Git blob 一致。

### 训练与对照

- 受控配对：采用作者 `reversal_routine` 的时序，先 B 配对 5 次，再 A 配对 6 次；产品相关试验将原有 shock 强化通道换为模型已有 sugar 通道。这是协议适配，不声称完整重现论文所有结果。同时跑了原始 shock 协议作为参照。
- 32 个随机种子均在 B 配对后形成 B 相对 A 的正向偏好；冻结可塑性及无奖励对照未形成对应 A/B 偏好。
- 奖励提前到气味之前的条件产生不同关联，作为时序诊断；它不是完全无关联的负对照。
- 改为 A 获得奖励后，A 的价值提高，但三对 MBON 的合并读出仍未完全转为 A 优先。因此只确认记忆发生更新，不宣称完成快速反转。
- 无奖励对照中仍有部分权重变化，但 A/B 无差异，说明不能单凭“权重动了”判定学会。

### GPU 记忆的行为测试

从磁盘 `gpu-trained-memory.npz` 载入 B 配对后的权重，在作者二维运动接口中测试。两种气味用不重叠 KC 输入（5/5，各 5 个活跃），其余运动参数 gain=0.05、noise=0.5，测试完全不提供奖励。每种条件使用相同的 32 个随机种子；交换气味源的位置，检查偏好是否跟随身份。

| 条件 | 未训练：B 附近时间 | 已训练：B 附近时间 |
|---|---:|---:|
| B 在左侧 | 11.4% | 97.1% |
| B 换到右侧 | 6.25% | 96.6% |

数字是 **步骤 51–99 中处于 B 半径 0.3 范围内的时间比例，再对 32 个种子求平均**，不是准确率或成功率。每种位置下各有 31/32 个种子在测试后半段超过一半时间待在 B 附近，并非每只每次都成功。例如未换位的种子 0 只有 6.1%；回放可以选择全部种子查看。展示图／回放默认例子为种子 1，统计包含种子 0，没有排除失败轨迹。

身体运动仍由作者的简化趋近接口完成，接口利用虚拟环境中气味源方向；这里验证的是学到的价值能改变行为，不是从像素学会自主定位。

### 自由探索训练的结果

另按作者示例和 YAML 的气味参数（KC 输入 7/6，存在重叠；5 个活跃 KC），100 个种子、每轮 100 步、重复 10 轮：仅 A 附近在训练阶段有奖励。使用作者回路与运动，另外比较冻结学习和无奖励条件。

第 10 轮，学习组在 A/B 附近的平均时间分别为 **37.8% / 37.5%**；冻结组约为 **8.2% / 9.3%**。模型学到了对这些线索的吸引，但没有形成我们希望的稳定 A/B 区分。第一轮只有 11% 的个体在奖励窗口接触过 A；输入重叠与有限奖励经历是需要区分的影响因素，本轮没有做足以断言单一根因的消融。

早期用构造器默认运动参数（gain=0.02、noise=0.1）摸底时，奖励接触更少；上述正式结果使用作者示例设置，没有为了得到成功数字调整学习率。

## 时间与 GPU 收益

在 Conda 环境中，用相同 sugar 配对序列比较原始 NumPy 和 PyTorch CUDA；GPU 用 float64，预热后 3 次取中位数。

| 工作负载 | CPU 原始模型 | GPU 批处理适配 |
|---|---:|---:|
| 单个模型，78 个更新步 | 13.3 ms | 89.9 ms |
| 32 个模型，相同协议 | 391.6 ms（逐个） | 106.3 ms（并行） |

GPU 对这批 32 个模型约快 **3.7 倍**，但单只模型 CPU 更快。此比较是朴素 NumPy 逐个运行与 GPU 批处理，不是优化 CPU 批处理的公平硬件极限测试；计时排除导入、GPU 初始化、数据传输与磁盘。逐步活动及权重的最大绝对差异为 **2.66×10⁻¹⁵**，检查覆盖 1 和 32 两种 batch。

包括对照、位置交换、100 个种子×10 轮×3 条件的自由环境评估，本轮正式评估约 **59.4 秒**。这与 GPU 的 0.106 秒训练核心是不同计时范围，不应混用。下载与准备时间不计入。

## 下一步判断
