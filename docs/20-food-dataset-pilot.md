# 食物关联训练的数据准备

状态更新：非食物素材已补充，已完成一次小规模 GPU 训练；当前标注、划分与结果见 [21](21-food-category-training.md)。本文以下为首次准备记录。

用户新增五张 B 站截图，先保存原图及前三排完整封面，忽略底部不完整的一排。按 2560×1229 原图尺寸换算预览坐标。

划分原则：先检查重复／近重复，再按来源分组划分训练、验证、测试；同一图片及增强版本不能跨集合。训练集给奖励，验证集选择有限训练设置，测试集只在设置确定后使用。此前反复观察过结果的两批截图不作为新的盲测测试集。

当前素材以食物主题为主，不能把“搜索美食得到的所有图片”都视为清晰食物正例，也不能把其中人物／课程封面自动视为非食物负例。动物、文字广告、食物真假不明等需标记待确认。缺少独立、内容多样的非食物图片时，只做数据准备，不报告食物分类或泛化成绩。

本轮不重新训练或更改正式桌宠。待补充非食物素材后，按可见内容标注，完成去重和分组划分，再开展小规模训练。无需大数据集或全脑微调。

已整理 [90 张完整封面及来源记录](../data/food-association-pilot/README.md)，目视核对五张拼图。批内近重复初筛未发现距离 ≤8 的 pHash 候选；跨历史素材的分组仍待最终划分时完成。当前标签与 split 均为待定，避免在负样本到齐前固定一个失衡的数据划分。
