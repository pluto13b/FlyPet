# 全脑桌宠接入

> 已完成的全脑接入记录。此后新增官方视觉独立观察、密集解剖图、系统光标合成及手动投喂；当前模块关系见 [项目进度](04-progress.md)。

本轮目标：把实测通过的 138639 神经元、15091983 连接的脑引擎作为桌宠默认大脑，而不是后台旁路演示。身体、字幕、观察和存档继续使用同一个体状态。

## 方案

- Electron 保留轻量身体循环；独立 Python/Numba 进程以 2 ms 时间步计算完整网络。使用逐次请求/响应，不堆积未计算帧。
- 复用已下载的完整连接图；补充公开眼柱映射，将现有屏幕采样分配给有实际解剖映射的感受器。鼠标几何刺激与屏幕像素输入分开标注。
- 全脑神经输出驱动 GF 逃逸、DNp09 行走、DNa 转向、DNg11 梳理。重新检查群体阈值和单位；不让旧 668 神经元引擎同时决定动作。
- 观察面板显示完整规模、全脑活动统计和运行速度。原有点云只作为带真实 ID 的局部探针，明确不是全脑点云。
- 保留个体 ID、年龄、内部变量、位置、事件；从小回路升级时全脑神经状态首次初始化，不宣称旧神经电位可无损映射。原 JSON 存档单独备份。
- 用配对检查点保存宠物状态与全脑动态（膜电位、突触电流、适应、不应期、延迟队列、随机状态和累计脉冲）。正常退出等待保存并终止子进程。
- 脑进程出错或没有新输出时暂停动作并显示故障；不悄悄退回小模型。

## 验证

验证真实全脑规模、屏幕输入收到并参与计算、GF 刺激和沉默因果、暂停、不堆积请求、全脑快照恢复后下一步一致。跑两次桌面集成测试检查同一个体与脑时间连续恢复；检查界面和现有平滑动作。正式升级前备份旧个体，完成后启动并检查日志和子进程。

本轮不加入食物识别或奖励学习，不把全脑接入称为已经实现完整生物行为。

## 实现与验收结果

- 默认脑引擎已改为独立 Python/Numba 全脑进程；保留全部 138639 个神经元和 15091983 条连接，2 ms 神经时间步、每次 50 ms 模拟块。旧小回路只用于基线测试，不参与默认行为决策。
- 光感受器映射来自公开 column_assignment：R7/R8 直接使用眼柱，R1-6 使用其对已映射 L1/L2/L3 的最强连接推定。实际映射 8753 个感受器到左右各 9×7 屏幕采样点；这是有解剖映射依据的粗采样，仍非完整生物视觉模型。
- 668 个局部探针全部找到全脑对应 ID。界面标明完整规模与局部点云范围，亮度来自对应细胞的实际活动，不生成虚构全脑动画。
- 实际脑电位、突触电流、适应、不应期、延迟缓冲、累计脉冲、随机状态与宠物信息保存在同一个 NPZ 检查点；JSON 是辅助摘要。首次从小回路升级保留身份/经历，神经状态重新初始化，并保留旧存档备份。
- 神经状态恢复后继续一步，与不重启的运行逐数组完全一致。GF 人工刺激、GF 沉默、像素输入测试通过；真实子进程结束后产品暂停，未退回小模型。
- 9 项 Node 测试通过。两次桌面集成通过，第二次全脑时间从 7750 ms 继续到 15700 ms，个体 ID 相同；暂停、按钮干预、实时屏幕输入、完整脑保存均通过。
- 桌面集成样本中，内核模拟 50 ms 的计算约 18 ms，末次待计算时间约 21 ms；这只是该工况瞬时记录，不代替整个应用性能测试。
- 正式进程升级与存档检查在末尾记录。

## 仍然是模型假设的部分

全脑连接符号继承数据；保持抑制增益 1.5、适应项，并将 GF 阈值提高 10 mV。屏幕亮度映射到感受器外部脉冲，鼠标几何驱动视觉群体；动机仍通过显式外部驱动调制相关群体。全脑的放电率不同于小模型，行走阈值由 7 Hz 调为 2 Hz。上述参数为工程建模选择，不是已测量的真实个体生理参数。

未接入奖励学习、食物识别或完整腹神经索。全脑网络接入不等于这些功能自然出现。

证据：output/whole-brain/runtime-test.json、output/verification/core-tests.txt、output/verification/desktop-smoke.json、data/whole-brain/runtime-map.json。

## 持续运行中发现并处理的调度问题
短测未暴露两项积累问题：脑批次完成后等待 UI 定时器，造成额外空等；Electron desktopCapturer 在持续采样时阻塞主线程，导致墙钟约 59 秒只推进约 33 秒模拟。先改为响应后立即接续，再将屏幕捕获放入现有独立 Python 进程，使用本机 Pillow/Win32；只回传 126 个亮度值，不传完整图像。跨 DPI 坐标由 Electron dipToScreenRect 转为物理像素。修复后重新持续验收，不沿用先前短测结论。
