# 全脑本机实测方案

> 历史实验方案，实测已完成；其后也已接入桌宠。独立性能结果见 [08](08-whole-brain-results.md)，当前状态见 [项目进度](04-progress.md)。

用户授权：进入全脑实测。先写方案，再执行。本轮不替换桌宠正在使用的 668 神经元模型，不改动正式个体存档。

## 数据与“全量”定义

首先测试 FlyWire FAFB v783 成年雌蝇脑公开连接组。下载官方 classification、consolidated_cell_types、connections 表。保留全部提供的神经元和连接记录，聚合同一神经元对的记录；不默认删除少于 5 个突触的连接。记录确切神经元数、连接对数、突触接触数、未知递质与分类缺失数量。

这是公开数据范围内的全脑简化模型，不包含完整身体/腹神经索，也不等同于完整生理复制。MaleCNS 不与本次 FlyWire 数量混用。

## 实现与测试

- 数据准备和 LIF 引擎由 FlyPet 编写；用 NumPy 紧凑数组，必要时用 Numba 编译循环，不使用当前 JS 小回路逐对象扩展。
- 复用本机 Python/NumPy/Pandas；新增依赖放在工作区虚拟环境。所有缓存、JIT 和临时文件指向工作区。
- 自研固定步长 LIF：膜电位、突触衰减、延迟、不应期及显式适应项；模型参数写入结果。基准中刺激是受控外部输入，不假装真实屏幕视觉。
- 对比 0.5、1、2 ms 步长。至少覆盖无输入、感觉刺激和分散持续输入，报告实际放电率，避免用沉默网络证明“全脑很快”。
- JIT/载入时间与稳态测量分开。输出模拟时间/墙钟时间比、运行内存、进程 CPU 时间、活动神经元、发放率与下行群体响应。
- 先做 CPU。如果 CPU 已满足实时且有余量，不为比较而安装庞大 GPU 栈；明确 GPU 未测。
- 保存机器可读 JSON 和中文结论。做一次持续实时调度检查，估计实时运行 CPU 占用及是否漏掉时间预算。基准不包含 Electron/截图/身体绘制开销。

## 验收

数据来源可查、真实完整连接图已经加载、运行出现可计数神经活动、报告每种工况而非单个漂亮数字。结论回答：能否实时、占用多少、哪个步长值得下一步接入、还有哪些能力没有证据。若出现不稳定神经活动，作为模型现象记录，不静默降低规模来通过性能测试。

下载通过 http://127.0.0.1:7897，原始/编译数据位于 data/whole-brain，代码位于 experiments/whole_brain，结果位于 output/whole-brain。

## 数据核对后的修订
Codex CSV 实际提供 139255 个分类神经元、2700513 个聚合连接对、34153566 个突触接触；未在本地删减，但并不覆盖论文仓库中的全部连接。追加获取 Shiu 论文仓库固定提交 91bdd1e7dcf193f3e7ca5a8933497fcef63b7960 的 Connectivity_783.parquet 和 Completeness_783.csv。该配套版本包含 138639 个神经元、15091983 条连接记录及 54492922 个突触接触，ID 与索引逐条对应，全部可以匹配 Codex 分类。正式性能测量采用这套配对数据；其余 616 个分类表神经元不作为虚构孤立节点加入。CSV 统计保留作差异记录。
